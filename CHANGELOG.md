# Changelog

## 0.2.0

- Music-first Search home with immediate play, play-next, Up Next, playlist, and download actions.
- Persistent custom playlists with create, rename, delete, deduplicated saves, track removal, playback, and enqueue controls.
- Persistent three-pane music library and directly manageable Up Next queue.
- Automatic next-track playback, unavailable-track skipping, previous-track history, and crash-safe current-track recovery.
- Mouse targets for search actions, playlists, playlist tracks, queue tracks, transport, seek, and volume.
- Direct URL command-line launches still open the Download workspace.
- Responsive compact Search layout that keeps play, queue, playlist, download, and resume controls visible.
- Restrained open-panel visual system, terminal-padding color blending, and confirmed history clearing.
- Global download preset flow from Search: `Shift+Enter` opens options and `Ctrl+Enter` queues immediately.
- Boundary-free action labels and a stricter responsive breakpoint prevent control-row overflow.

## 0.1.0

- Initial youTUIbe release, renamed from Tide; executable is `youtuibe`.
- Import legacy history and settings without deleting the original state.
- Search, real format selection, subtitle discovery, resilient download queue.
- Full mpv audio/video playback with timeline, volume, mute, and speed controls.
- Original compressed audio with embedded cover art; padded desktop thumbnails.
- Mouse dragging for quality, timeline, and volume sliders.
- Source and x86_64 binary release archives with AUR package metadata.
