# Changelog

## 0.1.0

- Initial youTUIbe release, renamed from Tide; executable is `youtuibe`.
- Import legacy history and settings without deleting the original state.
- Search, real format selection, subtitle discovery, resilient download queue.
- Full mpv audio/video playback with timeline, volume, mute, and speed controls.
- Original compressed audio with embedded cover art; padded desktop thumbnails.
- Mouse dragging for quality, timeline, and volume sliders.
- Source and x86_64 binary release archives with AUR package metadata.
